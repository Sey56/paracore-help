# Presets

A **preset** is a named set of parameter values for one Gallery script. Instead of filling the form the same way every time, you save it once and pick it again later.

On a script's **Parameters** tab, the **Presets** control shows `<Default Parameters>` when nothing is saved. Use it to create a preset from the values currently in the form, switch between presets, rename one, or delete one.

Presets belong to that script — they do not affect other scripts, and they do not change the script's code. If you edit the `Params` class later, the saved values still apply to the properties that remain.

See [Parameters and the Configurator](../scripting-reference/parameters.mdx) for how the form itself is built.
