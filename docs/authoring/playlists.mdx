# Playlists

A **playlist** runs several Gallery scripts in the order you choose. It is the third view in the desktop app, next to **REPL** and **Gallery**.

1. Open **Playlists** and click **New Playlist**.
2. Give it a name and add the Gallery scripts you want, in the order they should run.
3. Click **Run Playlist**.

Each script keeps its own parameter form and its own preset, so a playlist is just the order and the grouping — it does not merge or rewrite any script.

A playlist is useful for a repeated sequence, such as "check the model → export a report → apply the fix". Start with the [Gallery lessons](../tutorials/more-automation.md) if you do not have scripts to put in one yet.
