# How Paracore Fits Together

Four pieces, all on your computer.

![How Paracore fits together](/img/system-architecture.png)

| Piece | Job |
|---|---|
| **Paracore Desktop app** | The window you work in: the REPL editor, the Gallery, Playlists and results. |
| **Local connector** | A small service the desktop app starts for you. It passes scripts and results back and forth. |
| **Paracore Revit add-in** | Runs inside Revit and gives the code direct access to the open model. |
| **CoreScript engine** | Compiles and runs the C#. The REPL, Gallery scripts and AI assistants all use this same engine. |

Because there is one engine, a line of C# behaves the same wherever you write it. The only differences between the REPL and a Gallery script are where the code is stored and whether it has a parameter form.

Everything stays local: no model data is sent to a server unless you choose to use an AI assistant.
