# Welcome to Paracore

Paracore runs C# scripts **inside Autodesk Revit**, while Revit is open. Write a line, press <kbd>Ctrl</kbd>+<kbd>Enter</kbd>, read the answer. Nothing to compile, no restart.

![The Paracore desktop app](/img/ui-4.8.3-first-run.png)

Two pieces are required; two are optional.

| Piece | What it does | Needed? |
|---|---|---|
| **Paracore Revit add-in** | Runs your code inside Revit | Yes |
| **Paracore Desktop app** | Where you write, configure and run scripts | Yes |
| **CoreScript VS Code extension** | Standalone tool for writing **and running** C# from VS Code instead of the desktop app | Optional — not needed to edit scripts |
| **Paracore-Gen** | Lets an AI assistant write and run scripts in Revit | Optional |

The difference between plain VS Code and the CoreScript extension is explained under [Downloads](./getting-started/downloads.md).

## The three views

The desktop app has three buttons at the top:

- **REPL** — type C#, press <kbd>Ctrl</kbd>+<kbd>Enter</kbd>, read the answer in **History**. Tables and charts go to **Analytics**. These are two tabs on the output panel: only one is visible at a time. If the hidden tab receives output, a blue dot appears on its name; activating the tab clears the dot.
- **Gallery** — saved scripts you run again and again, each with an optional input form.
- **Playlists** — several Gallery scripts run in order. [Reference](./authoring/playlists.mdx) · [Lessons](./tutorials/playlists.md).

All three views feed the same output panel: text to **History**, tables and charts to **Analytics**. The REPL and Gallery use the same engine and the same C#. Every script runs against the **active document in the open Revit session** — `Doc` is that live model, not a file on disk.

## What the code looks like

Paracore supplies short calls in place of Revit's setup boilerplate:

```csharp
GetElements<Wall>().Count()
```

```csharp
GetElements("Rooms")
    .GroupByParam("Level", "Area", "m2")
    .BarGraph()
```

These are ordinary C# extension methods; the raw Revit API still works alongside them. See [The REPL Playground](./interactive-repl/index.mdx).
