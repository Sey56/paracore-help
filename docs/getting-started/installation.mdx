# Install and Connect

About five minutes. Do these in order.

## Requirements

- **Windows 10 or 11 (64-bit)**
- **Autodesk Revit 2025, 2026 or 2027**
- **Visual Studio Code** — needed only if you write Gallery scripts. This is the plain editor; the **C# Dev Kit** extension from Microsoft is optional and only adds autocomplete. You do **not** need the [CoreScript VS Code extension](../corescript-vscode/index.mdx) to edit scripts — the desktop app opens VS Code directly.

You do not need to install .NET separately. Everything needed to run a script comes with the add-in.

## 1. Install the Revit add-in

**Close Revit first.** Run `Paracore_Addin_v4.8.3.exe` as administrator. The installer shows a checkbox for each Revit version it finds on your machine — tick the ones you use. One installer covers 2025, 2026 and 2027.

## 2. Switch the server on

1. Open Revit and open a project.
2. Go to the **Paracore** ribbon tab.
3. Click **Paracore Server**. The button starts with a red circle and **OFF**; after the click it shows a green circle and **ON**. A Revit dialog confirms the connection — close it.

![Paracore Server switched on](/img/ui-4.8.3-server-on.png)

Nothing else runs until this button is **ON**.

## 3. Install the desktop app

Run `Paracore_4.8.3_x64.msi`. Open **Paracore Desktop** and wait a few seconds while its local connector starts.

The status in the top bar turns from red **Disconnected** to green **Connected**. If it stays red, check that the server in step 2 is **ON** and that Revit has finished loading.

## 4. Optional extras

Neither is needed to edit or run Gallery scripts.

- **CoreScript VS Code extension** — a standalone tool for developers who want to write **and run** C# straight from VS Code **without the desktop app**. The desktop app has no connection to it and never uses it; editing needs only plain VS Code.
- **Paracore-Gen** — install it only if you want to use an AI assistant such as Claude Desktop with Revit.

Both are on the [downloads page](./downloads.md), which also explains the difference between VS Code and the extension.
