# Getting Started

Three steps and you are running code in Revit.

1. **[Install and connect](./installation.mdx)** — install the add-in and the desktop app, then switch the server on in Revit.
2. **[Downloads](./downloads.md)** — where to get all four installers.
3. **[Your first script](./first-script.mdx)** — one line of C# to prove everything works.

Then pick a learning path:

- **[REPL lessons](../tutorials/index.md)** — eight short lessons. Nothing to install or save.
- **[Gallery lessons](../tutorials/more-automation.md)** — build scripts with input forms that you keep and reuse.

## What you need

- **Windows 10 or 11 (64-bit)** and **Autodesk Revit 2025, 2026 or 2027**.
- **Visual Studio Code** — only if you want to write Gallery scripts. The desktop app opens VS Code for you directly. You do **not** need the [CoreScript VS Code extension](../corescript-vscode/index.mdx) to edit scripts.

You do **not** need to install .NET separately to run scripts.
