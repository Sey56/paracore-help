# Getting Started

Welcome to **Paracore**! This guide will help you get up and running in minutes, from initial installation to running your first high-performance Revit automation.

## The Path to Success

1. **[Installation & Setup](./installation.mdx)**: Set up the Add-in, activate the server, and connect the Desktop app.
2. **[Your First Script](./first-script.mdx)**: Execute a sample automation to verify your setup.
3. **[Downloads](./downloads.md)**: Get the latest installers.

## Prerequisites

Before you begin, ensure you have a compatible environment:

- **Autodesk Revit**: Version 2025 or later.
- **Windows 10/11**: 64-bit version.
- **Visual Studio Code**: Required for Authoring. Paracore integrates directly with VS Code to provide a professional editing environment.

## What's New in v4.8 (October 2026)

- **One generic engine**: `paracore-pro` is gone — one engine, one add-in, always free. Only the specialist MCP servers stay commercial.
- **Sentinels are free**: the background watchdog now ships in the free engine — no enterprise gate.
- **Packs**: a specialist feature installs as a pack — an assembly kept outside the add-in folder, one ribbon button each.
- **REPL errors point at your code**: a syntax error reports the line and column you actually typed.
- **Paracore-Gen v2.0.0**: the generalist MCP server (previously Paracore MCP) now ships as its own installer, with new `get_context`, `pick_object` and `export_view` tools.

> Full Details: Read the [Release Notes](../release-notes.md) for a comprehensive list of changes.
