# Your First Script

This takes one minute and proves the whole chain works: desktop app → local connector → Revit.

## Before you start

1. Revit is open with a project, and **Paracore Server** on the **Paracore** ribbon tab is **ON**.
2. The desktop app shows a green **Connected** in the top bar.
3. The **REPL** button at the top is selected.

If any of these is missing, go back to [Install and Connect](./installation.mdx).

## Run one line

Type this into the **REPL Playground** editor:

```csharp
Println("Hello");
```

Press <kbd>Ctrl</kbd>+<kbd>Enter</kbd>. **History** shows a marker `> REPL Playground` and, under it, `Hello`.

![Your first run in the Paracore desktop app](/img/ui-4.8.3-first-run.png)

Now try something from the model:

```csharp
GetElements("Rooms").Count()
```

A number appears. The expression is **bare** — no semicolon — so it prints its result on
its own. Add a semicolon and it becomes a statement that prints nothing; use `Println` to
label a result instead.

:::tip[Expressions and statements — the one rule]

The panel is a code editor **and** a prompt at the same time, so it obeys both sets of rules.

| You type | What you get |
|---|---|
| `GetElements("Walls").Count()` | the number — a **bare expression** prints itself |
| `GetElements("Walls").Count();` | **nothing** — the `;` turns it into a statement |
| `Println($"Walls: {GetElements("Walls").Count()}")` | the label, with or without `;` |
| `var walls = GetElements("Walls");` | **nothing, always** — an assignment is a statement |

- A **semicolon ends a statement**. A statement does work; it does not produce a value to show.
- An **assignment is always a statement**: `var walls = …` stores the walls for later and never
  echoes them. It always needs its `;`.
- **Only the last line can be bare.** If you write several lines, every line before the last needs
  its `;`, otherwise you get `CS1002: ; expected`.

Silence is therefore normal, not a failure: an assignment or a `;` simply has nothing to print.

:::

## What just happened

Your C# was compiled and run inside the open Revit document. No file was saved, no project was created, and Revit never restarted. That is the whole idea behind the REPL.

If you save the snippet as `HelloParacore.cs`, the History marker changes from `> REPL Playground` to `> HelloParacore`. **History keeps results, not the code you typed** — it is read-only, with only **Copy** and **Clear**. To run something again, type it again, or use **Open** to bring back a saved snippet, then press <kbd>Ctrl</kbd>+<kbd>Enter</kbd>.
