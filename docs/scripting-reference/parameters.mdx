# Parameters and the Configurator

A Gallery script can have a small input form. You define it once in C# and Paracore builds the controls for you.

## The Params class

Put a public class named `Params` at the bottom of the entry script (or in its own `Params.cs` file). Every public property becomes one control.

```csharp
var p = new Params();
Println($"Level: {p.StartLevel.Name}");

public class Params
{
    public string Prefix { get; set; } = "A-";
    public int Count { get; set; } = 10;
    public Level StartLevel { get; set; }
}
```

Defaults are the values you see the first time you open the form. The app remembers the values you last used, so you don't have to retype them on every run.

## What each type becomes

| C# type | Control |
|---|---|
| `string` | Text box |
| `bool` | Toggle |
| `int`, `double` | Number box |
| A Revit type such as `Level` or `WallType` | Dropdown filled from the open model |
| A list of Revit elements | Multi-select list |

## Attributes

Attributes change how a control behaves:

| Attribute | Effect |
|---|---|
| `[Unit("mm")]` | Converts the value you type into Revit's internal units before the script sees it |
| `[Range(0, 100)]` | Adds a slider |
| `[Required]` | Stops the run if the field is empty |
| `[Segmented]` | Shows a set of choice buttons instead of a dropdown |
| `[EnabledWhen(...)]` | Shows or enables a control depending on another value |
| `[Confirm]` | Asks for confirmation before a destructive run |
| `[Select]`, `[RevitElements]` | Pick elements directly in the Revit viewport |
| `[InputFile]`, `[OutputFile]`, `[FolderPath]` | File, save-file and folder pickers |
| `[Suffix]` | A small unit label next to a number |

## Custom dropdown contents

Name a property `Something_Options` and it supplies the choices for `Something`:

```csharp
public class Params
{
    public WallType MyWallType { get; set; }

    public List<WallType> MyWallType_Options =>
        GetElements<WallType>().Where(w => w.Name.Contains("Generic")).ToList();
}
```

Without an `_Options` property, Paracore fills the dropdown from the open model automatically.
