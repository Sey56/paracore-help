# The REPL Playground

The **REPL** tab is a **full C# scripting environment** running inside Revit. You write C#, press <kbd>Ctrl</kbd>+<kbd>Enter</kbd>, and the answer appears. Nothing is saved unless you choose to save it.

## A full C# scripting environment

The REPL uses C# 9 **top-level statements**: no `Main`, no project file, no class wrapping your code. Echoing bare expressions is a REPL feature layered on top — it is not a limit on the language. Anything you can write in a C# script is available here: variables, local functions, LINQ, generics, classes, interfaces, structs, enums and records, and the complete Revit API.

**The distinction is what the code runs against: the active document in the open Revit session.** This is not a standalone C# process working on a file on disk. The script executes inside Revit, and `Doc` is the live project you have open right now — its elements, parameters, views and transactions. A query reads the model as it stands at that moment; a change lands in that open model. That is what makes this environment more powerful than a general-purpose script runner, not a smaller language. A project must be open for a script to run.

The one structural constraint is that a REPL script is **a single file**. You cannot split it across files the way a [Gallery script](../tutorials/gallery-04-modular-scripts.md) can. That is the only difference in language power — a script as long and as complex as you need still fits in this one file.

Keep the top-level-statement order:

```csharp
// 1. using directives first
using System.Text;

// 2. top-level logic
var walls = GetElements<Wall>();
var label = new WallLabel();
Println(label.Describe(walls.Count));

// 3. user-defined types last
public interface ILabel { string Describe(int count); }

public class WallLabel : ILabel
{
    public string Describe(int count)
    {
        var sb = new StringBuilder();
        return sb.Append("Walls: ").Append(count).ToString();
    }
}
```

`using` directives come before the statements, and type declarations come after them. Most common namespaces — `System`, `System.IO`, LINQ and the Revit API — are already pre-imported, so you only add a `using` for one that is not.

Paracore's extension methods (`GetElements`, `.WhereParam`, `.Table`, …) are shorthand for raw Revit API boilerplate. Nothing is fenced off: `new FilteredElementCollector(Doc).OfClass(typeof(Wall))`, `Wall.Create(...)`, `Transact(...)`, transactions and every other Revit API call work exactly as they do in a normal add-in. Use the shortcuts where they save typing and the raw API wherever you need it.

## The editor

The panel is called **REPL Playground**. Its toolbar gives you **New**, **Clear**, **Open**, **Save**, **Save As** and **Recent Files**. Saved snippets open in the same editor; their name appears in History instead of `REPL Playground`.

A bare expression prints its own result:

```csharp
GetElements<Wall>().Count()
```

The expression must be **bare** — no semicolon. A trailing semicolon turns it into a
statement, and a statement prints nothing. Drop the semicolon to see the value on its own:

```csharp
GetElements<Wall>().Count()   // prints, e.g. 9
GetElements<Wall>().Count();  // prints nothing — it is a statement
```

⚠ **This changes what you see, not what happens.** The code runs identically with or without the
final `;` — the semicolon only decides whether the result is echoed. A write proves it:

```csharp
GetElements("Walls").SetParam("Comments", "Done")    // writes, and lists the walls it changed
GetElements("Walls").SetParam("Comments", "Done");   // writes just the same, silently
```

Where the semicolon **is** required is anywhere except the end: in a multi-line submission every
line before the last must end with `;`, or the whole snippet fails with `CS1002: ; expected` and
nothing runs.

Use `Println(...)` when you want to label something:

```csharp
Println($"Walls: {GetElements<Wall>().Count()}");
```

## The two results tabs

- **History** — one entry per run. Each entry starts with `> REPL Playground` (or the name of a saved snippet), followed by the output and how long it took. **History keeps results, not the code you typed.** It is read-only: you can **Copy** the transcript or **Clear** it. Clicking an entry does **not** re-run anything. To run something again, type it again, or use **Open** to bring back a saved snippet, then press <kbd>Ctrl</kbd>+<kbd>Enter</kbd>.
- **Analytics** — tables and charts produced by `.Table()`, `.BarGraph()`, `.PieGraph()` and `.LineGraph()`.

## Tables and charts

```csharp
GetElements("Rooms")
    .GroupByParam("Level", "Area", "m2")
    .BarGraph()
```

The name you give each value becomes the axis label. If you want a label with a space in it, use a dictionary key instead of a C# property name — for example `"Total Area"`.

## Files

In the interactive REPL, file work goes through the `Files` helpers and stays inside the REPL workspace folder. Use short, relative names:

```csharp
var csv = string.Join("\n", GetElements("Walls").Select(w => w.GetStr("Type Name")));
Files.WriteText("out.csv", csv);
```

Absolute paths such as `C:\tmp\room-check` are not accepted here. Gallery scripts use `System.IO` directly and can work with any path — see [File-based Gallery scripts](../tutorials/gallery-07-file-io.md).

## If a script runs too long

A runaway script is stopped automatically and Revit becomes responsive again. If a long script needs more time, put this on its **first line**:

```csharp
SetExecutionTimeout(120);
```

The number is seconds. Use it as a safety net when you are unsure whether a complex script might hang.

## Check the parameter name first

A parameter name can be spelled perfectly and still be the wrong name for the element you are
reading. `Top Offset` belongs to Walls — Doors do not have it. That is not a spelling mistake,
so a spelling check will not catch it.

**Check the names before you read:**

```csharp
GetElements("Doors").First().CombinedParams().Table()
```

That lists every parameter doors really have, on the element and on its type. If your name is not
in that list, do not use it.
