# Script Sources and the Gallery

A REPL snippet lives in the editor. A **Gallery script** lives in a folder on your disk. The desktop app finds, configures and runs those folders — it is not a code editor.

## The shape of a script source

A **script source** is any folder containing a small marker file named `.paracore`. Inside it, each script is its own folder:

```text
MyScriptSource/
    .paracore
    HelloWall/
        Scripts/
            HelloWall.cs      ← the entry script (top-level C# + optional Params class)
            Helper.cs         ← optional
            Params.cs         ← optional
    RoomAudit/
        Scripts/
            RoomAudit.cs
```

The engine reads the `.cs` files inside `Scripts/` together, so one script can be split across several files. The `.csproj`, `.sln`, `Globals.cs`, `bin` and `obj` items that appear later are **only there for VS Code autocomplete** — they are not part of the script.

## Adding a source

Open the **hamburger menu** in the top-left of the desktop app. In the Sidebar, under **Local Sources**, click **Load or Initialize Source**. Pick an empty folder and choose **Initialize Script Source**, then **Initialize**. Paracore writes the `.paracore` marker and makes that source active.

![Local Sources in the Sidebar](/img/ui-4.8.3-local-sources.png)

To load an existing source, pick the folder that already contains `.paracore` — not its parent.

## Creating a script

In the **Gallery** view, with the right source selected under **Local Sources**:

1. Click **NEW**, give the script a name **with no spaces**.
2. Pick **Archetype** for a blank script, or **Builder** to build a filter visually.
3. Click **Generate Script**. A card appears in the Gallery.
4. Click **Edit Script**. This opens the script in VS Code **and creates the IntelliSense workspace files** the first time.
5. Back in the desktop app, set the parameters and click **Run**.
