# 10 - Step-by-Step: Paracore REPL

Practice interactive C# exploration and action chains in the Revit environment.

## 1. Preparation
1. In Revit, **Select at least one element** (e.g., a Wall or Room) in the active view.

## 2. The echo
1. In Paracore, open the **REPL** tab and click the REPL Playground editor.
2. Type `Selection[0].Id` — **no semicolon** — and press **CTRL + ENTER**.
3. The id comes back in the execution history. That is the echo: the last expression is printed for you.
4. Now type `Selection[0].Id;` **with** the semicolon and run it again. Nothing is printed — it is a statement now, and statements have no value to show.
5. Scroll back through the **History** tab to review the runs. Each one starts with a `> REPL Playground` marker (or the saved snippet's name) followed by its output — the code itself is not kept there. It is read-only: to run something again, type it into the editor again and press **CTRL + ENTER**, or **Open** a snippet you saved earlier. **Copy** takes the whole transcript; **Clear** empties the tab.

## 3. Persistent state
1. In the same editor, type:
   ```csharp
   var walls = GetElements<Wall>();
   Println($"Found {walls.Count} walls");
   ```
2. Press **CTRL + ENTER** to execute.
3. Clear the editor, then type `walls.Count()` on its own and run it — the variable from the previous turn is still alive.
4. Type `vars` (no semicolon) to list everything the session is holding, and `reset` when you want a clean slate.

## 4. Extension Method Power
1. **Action Chains**: In the REPL, type:
   `GetElements<Room>().Table().Select().Zoom();`
2. **Batch Actions**: Type `GetElements<Wall>().Hide();` and observe Revit.

## 5. Saving Snippets
1. Click the **Save** or **Save As** icons in the editor header.
2. Name your snippet and save it as a `.cs` file — the same file can be pasted into a Gallery script later.
