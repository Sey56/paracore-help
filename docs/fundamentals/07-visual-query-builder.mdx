# Visual Query Builder

Sometimes you know *what* you want to find in the model but not the C# for it. The **Builder** tab writes that C# for you.

In the **Gallery**, click **NEW**. The dialog has two tabs:

- **Builder** — choose a category, add conditions on its parameters, pick the columns you want to see. Paracore generates the filter code and the matching `Params` class.
- **Archetype** — a blank script, if you would rather write the C# yourself.

The generated script is an ordinary Gallery script: it lands in your active script source, opens in VS Code with **Edit Script**, and runs from the desktop app like any other. You can edit the generated code afterwards — nothing is locked.

If you are learning the engine, the [REPL lessons](../tutorials/index.md) are a better starting point; they teach the same calls in short, readable lines.
