# AI Assistants and MCP

**Paracore-Gen** connects an AI assistant to your open Revit model. You describe what you want in plain language; the assistant **writes C# and runs it in Revit** — it is not just a code generator.

It is an optional, separate installer on the [downloads page](../getting-started/downloads.md). The platform works fully without it.

## What you can use it with

Claude Desktop, Cursor, VS Code, or any client that speaks MCP. Point the client at Paracore-Gen; it connects to the same local service and the same add-in as the desktop app.

## What it can do

- Look at the model: categories, levels, parameters and element counts.
- Write and run a script to answer a question or make a change.
- Show you the code and ask for your approval before a run touches the model.

## What keeps it safe

- The script runs on the same REPL channel as your own code, so file access is confined to the workspace folder and a script cannot read or write elsewhere on your machine. On top of that channel guard, the agent's generated code is also blocked from the machine capabilities it must not reach — network, process launching, reflection, native interop — because the code is generated, not typed by you.
- Dangerous operations are restricted, and a runaway script is stopped automatically.
- You see the code before it executes, so nothing happens unseen.

If you prefer to write the C# yourself, everything an AI assistant can do is also available in the [REPL](../tutorials/index.md).
