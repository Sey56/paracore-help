# AI Assistants and MCP

**Paracore-Gen** connects an AI assistant to your open Revit model. You describe what you want in plain language; the assistant **writes C# and runs it in Revit** — it is not just a code generator.

It is an optional, separate installer on the [downloads page](../getting-started/downloads.md). The platform works fully without it.

## What you can use it with

Claude Desktop, Cursor, VS Code, or any client that speaks MCP. Point the client at Paracore-Gen; it connects to the same local service and the same add-in as the desktop app.

## What it can do

There is no fixed list of operations. Paracore-Gen writes a new C# script for each request, so anything you can describe — reading, editing, creating geometry, multi-step work — is done by code written at that moment. Have that conversation in Claude Desktop, Cursor, VS Code or any client that speaks MCP.

- Look at the model: categories, levels, parameters and element counts.
- Write and run a script to answer a question or make a change.
- Show you the code and ask for your approval before a run touches the model.

## What keeps generated code in bounds

- Generated code can contain anything, so it cannot name machine capabilities it does not need: network, process launching, reflection, native interop, and on the REPL channel `System.IO` and threads. See [How Paracore-Gen works](./how-it-works.mdx) for the boundary and why it exists.
- Dangerous operations are restricted, and a runaway script is stopped automatically.
- You see the code before it executes, so nothing happens unseen.

If you prefer to write the C# yourself, everything an AI assistant can do is also available in the [REPL](../tutorials/index.md) — and the assistant can help you there too. As well as making a change for you, it can simply **give you the code** to run yourself. Ask it for the script instead of asking it to do the edit: for example, *"Give me a REPL script that renumbers the doors"* or *"Give me the C# to create a wall between two points"* rather than *"Renumber the doors"* or *"Create a wall"*. It returns the C#; you paste it into the REPL and run it on your own terms.
